## Getting Started

1. Clone the repository

```bash
git clone https://github.com/17Sx/Portfolio2026v2.git
```

1. Enter the project directory

```bash
cd Portfolio2026v2
```

1. Install dependencies

```bash
npm install
```

1. Start the development server

```bash
npm run dev
```

The site runs on `http://localhost:5173`.
